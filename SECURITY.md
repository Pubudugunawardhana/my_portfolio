# Security Policy

## Supported versions

Only the latest version on the `master` branch (the live site at
<https://pubudugunawardhana.vercel.app>) receives security fixes.

## Reporting a vulnerability

**Please do not report security issues in public GitHub issues, discussions or pull requests.**

Report them privately through GitHub instead:

1. Go to the [**Security** tab](https://github.com/Pubudugunawardhana/my_portfolio/security) of this repository.
2. Click **Report a vulnerability**.
3. Include as much as you can:
   - what the issue is and where it is (URL, page, file or API route)
   - steps to reproduce it
   - what an attacker could do with it

You can expect:

- an acknowledgement within **3 days**
- an update on the fix within **14 days**
- credit in the fix notes, if you would like it

Please give me reasonable time to fix the issue before sharing it publicly.

## Scope

In scope:

- the portfolio site and its API routes (`/api/*`)
- the admin panel and sign-in (`/login`, `/admin/*`)
- the source code in this repository

Out of scope:

- denial-of-service or load testing
- spam or social-engineering attacks
- issues in third-party services (Vercel, MongoDB Atlas, Cloudinary, Google, Medium) – please report those to the vendor

Thank you for helping keep this project safe.
